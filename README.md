# AI-SDLC Product Engineer Re-skilling

Proyecto de portfolio y web formativa para perfiles de Product Owner y Business Analyst que quieren modernizarse hacia Product Engineer con metodologías basadas en IA.

## Objetivo

Mostrar un itinerario profesional técnico y académico para:

- entender la transición de la lógica funcional a la lógica de producto/entrega,
- aplicar la metodología AI-SDLC,
- documentar el aprendizaje como parte de un portfolio personal,
- preparar la base para subir el proyecto a GitHub y publicarlo.

## Stack

- HTML5
- CSS3
- JavaScript vanilla
- Git + GitHub

## Estructura

- `assets/`: recursos visuales
- `css/`: estilos globales y secciones
- `docs/`: documentación y referencias
- `js/`: lógica interactiva
- `index.html`: página principal

## Ejecutar localmente

```bash
python -m http.server 8000
```

Luego abre:

```text
http://localhost:8000
```

## Propósito

Este proyecto busca demostrar progreso real en desarrollo web, GitHub, documentación técnica y narrativa profesional orientada a transformación digital con IA.
